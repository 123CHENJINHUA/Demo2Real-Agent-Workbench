## 总控 Agent 的运行时失败处理

- 各阶段失败统一提交总控，携带当前场景、失败判据、最近仿真回合与先前修正结果。总控从当前阶段登记的能力里选择重试、修正场景、重新规划动作、请求必要输入或保留阻塞。接触、支撑失稳和未达判据作为决策证据。场景修正由本次运行的匹配视图和几何测量决定。
- 场景专责修正后先通过独立检查。动作专家在该候选场景复测，后续重规划继续使用该版本。冻结验收文件、阶段绑定及录制轨迹校验保持一致。只有相关动作复测通过才发布修正版。每阶段最多三轮总控决策，同一证据下的同一修正会被拦截。用户在「运行进度」查看总控解释和对应处理记录。
- 工作进程启动失败或退出不留有效结果时，调度器记录运行时异常供排查。模拟模型夹具验证了场景复测后转给动作专家、沿用新版场景、拒绝改写冻结阶段、未知动作拒绝、重复修正停止和真正需要用户输入时进对话。80 项选定 Python 回归与前端构建、组件检查通过。未对正式光伏任务启动新运行或调用外部模型。
