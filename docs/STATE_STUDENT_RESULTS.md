# 状态恢复学生：实际进展与范围

用户已跳过RGBD对照，本轮单开发Agent，未调用额外LLM。业务文件、权重、数据和日志均在本项目；外置环境只读；硬件命令0。

## 本轮实现

- 真实PhysX恢复采集：24维模拟位姿/关节/夹爪派生特征，独立来源契约。无力输入、无扰动种类特征、无物体瞬移/夹爪固定连接。
- 五类高层技能学生：continue、wait、regrasp_left、regrasp_right、needs_human。底层连续示教适配/IK/双臂协调保持确定性。
- 数据按回合分割，旧10个冻结位姿留出回合禁止入训练；混合采集器源码版本拒绝。重抓标签仅收录实际物理重抓成功的对应样本，失败不改成成功。
- 新模块独立：modules/learning/recovery_dataset.py、recovery_bc.py；modules/policies/neural/recovery_supervisor；modules/evaluation/recovery*.py；modules/deployment/recovery.py。
- API四阶段训练作业与前端真实进度/指标/权重；独立闭环测试入口，输出神经原始动作、守卫覆盖、实际恢复与插接结果。
