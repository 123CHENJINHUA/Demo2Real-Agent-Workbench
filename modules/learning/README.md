# 学习模块

首版提供真实NumPy高层BC：8→32→5 MLP，episode级训练/验证/测试分割，验证集选权重，保留测试集。NPZ需features/labels/episode_ids/split/metadata，metadata需features列表、observation_source=camera_estimate、dependency_signature。特征不能包含仿真真值或扰动标签；标签可由专家生成。

该模型只学习技能分类，不是双臂连续策略，不代表任务已泛化。需要额外闭环、扰动、墙钟时延、硬件范围评价；无有效本任务数据时明确待配置。

## 示教动作专家学习

新示教从总控提案读取目标、步骤和成功条件，再结合当前场景、录制画面及相关历史案例生成本次动作计划。每个阶段为参与动作的机械臂设定物体坐标系或世界坐标系下的目标点、朝向和夹爪开度。步骤和目标点数量随任务生成。历史案例只提供可重新取证的经验，每条引用留有采用或跳过的理由。刚性面板模板保留在独立的显式实验入口。

新专家用录制首帧初始化逆运动学，根据当前场景的目标点逐段生成自己的关节与夹爪命令。Isaac 每轮测量接触、物体位姿和冻结判据。学习器优先处理最早失败的阶段，依据碰撞方向、开度不足或目标区域误差调整相应目标点。候选排序保留通过的连续阶段及尚未通过的量化进展。相同参数不重复试验。每次搜索最多 18 轮，保留参数、回合、选中依据和首次阻塞。旧版计划仍可走录制轨迹微调。

已知需要共同移动的组件和支撑保持分组。独立验收方案先冻结，再用同一组条件比较录制轨迹与冻结后的专家。留出布局只用于验收。缺少合法位置变化时仅报告示教布局。当前目标点参照场景重置时的物体位姿，当前执行接口基于 Nero 双臂和已绑定的刚体。

产物存入各条示教的 `simulation/action_program_*`，包含动作计划、验收判据、冻结输入、专家参数、逐回合轨迹和报告。该阶段产出离线动作专家，单独的学生策略训练仍有自己的数据契约。
