# 接触中心重抓规划v2

regrasp.py只依赖NumPy/SciPy和本项目几何读取器，不导入Isaac/SDK。输入真实关节状态、示教迁移抓姿、物体与手部几何；输出完整关节路径和预检报告。执行模块在modules/skills/connector_regrasp.py，通过运行器提供的端口运动。

先保留名义抓姿，依次尝试±5°到±30°绕夹爪闭合轴倾角，夹持中心和闭合轴保持。先使用撤退姿态到夹持中心上方3–7cm，再让夹持中心下降并渐变手腕姿态。抬升反向渐变，避免原固定倾角的上方目标不可解。预检接近、下降、抬升、回程的原IK精度/URDF限位和每步≤0.015rad关节插值。

桌面检查使用真实手部网格顶点（张开/闭合包络），另检查另一Connector的保守圆柱包络。尚非完整机械臂/相机/所有障碍物的连续碰撞规划，不能据此声明实机无碰撞。未建模的现实障碍仍需补建与验证。

仅显式skill_version=contact_center_v2启用，legacy_v1保留。无候选时不执行未检查的抓取路径；输出原因并请求人工。真实PhysX夹持和抬升确认独立执行，不用物体瞬移或固定连接。
