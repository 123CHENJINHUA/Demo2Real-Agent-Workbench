# Nero 模型与标定自动读取

示教元数据声明 `nero_dual_follower` 时，流程读取项目内 `assets/nero/` 的双臂 URDF 与网格，并在 `calibration/` 或 `assets/calibration/` 查找匹配的标定包。单个兼容包自动选用，多个包可通过示教元数据或运行创建接口的 `calibration_bundle` 指定。

标定包可以整体移动。入口依据 `bundle.json` 声明从同目录读取左右腕、中间相机与双臂 TCP。文件路径、哈希、变换方向及测量验收状态随任务定义和轨迹审查保存。已有冻结任务继续引用保存的资产。

场景预览使用双臂基线、共同朝上方向、桌面边缘和中间相机视线自动估计 `T_scene_calibration_board`，并保存所采用的 SDK 基座与 URDF 根重合假设。已配置双臂的任务使用本身的场景位姿。估计的双臂和三台相机用于离线预览，保持记录中的基座相对变换和腕部手眼。关节回放仍按所用模型核对完整轨迹的限位。
