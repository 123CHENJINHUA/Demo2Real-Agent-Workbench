# 场景构建

输入独立task-spec/v1快照，经hash/路径检查后在登记Isaac子进程构建。USD、真实全景/腕相机图像、相机投影核验、PhysX局部落桌记录和输入依赖存于本次runs目录。

预览允许draft，不把它当完整动作/接触可靠性通过；contact_execution_authorized始终false。Connector专用被动锁扣几何通过注册组件接入；程序生成box走同一通用构建器，不继承Connector功能参数。未知对象尺度/位姿会停在待配置。

不调用控制器、规划策略、SDK或真实设备。场景建成与完整抓取/插入/松手后保持是不同验收层级。

布局可把本回合的动作候选与同一时间附近的示教图像关联，为初始摆放增加工具位姿约束。场景快照保留估算依据及结果。碰撞几何 Agent 根据参考网格的截面、可见动作和已记录的物理问题提出独立碰撞候选，源文件和可视模型保留。验证报告与候选场景一起存入本次运行，局部检查失败时继续使用原碰撞几何参与正常场景检查。
