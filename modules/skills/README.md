# 技能执行边界

connector_regrasp.py是Nero/Connector的显式v2实现，通过sim端口读取机器人/估计观测、调用纯规划模块，再提交预检关节路径。它不导入Isaac或SDK，不写物体位姿，不创建夹爪固定连接。

报告字段分层：规划报告passed表示数值/几何预检；physical_grasp.passed表示该次实际抬升与夹爪间距确认；recovery_policy.recoveries中的passed表示恢复流程已返回；完整动作由独立expert_validation另验。不能把其中任一局部通过写成完整任务成功。

当前几何/接触偏置适用于现有Nero和Connector资产；其他任务需自身前置条件、手部几何及对应规划插件。当前桌面重抓不覆盖插接阶段所有夹持异常。真实硬件经独立执行层，不直接复用本sim端口发命令。


## 插接阶段与失败退出（v3显式启用）

`insertion_recovery.py`经阶段护栏选择暂停、有限卸载、原位重新夹持或放弃；v2网络提议与实际执行分别记录。重夹位姿/宽度确认不等于双指物理接触，接触验收字段独立保存。

`failure_exit.py`执行用户指定的“失败松爪归位”：停止任务，张开双爪，确认开爪，物体自然释放，通过`planning.return_home`预检的受限关节目标返回本回合载入的初始关节姿态，并保持开爪。归位不使用物体写入/关节瞬移/固定连接，不请求人工。若开爪、路径或跟踪失败，报告`passed=false`，不伪称归位完成。

当前路径预检覆盖关节限位和实际手部网格与桌面的间隙，尚非全机械臂与任意障碍物的碰撞保证。此实现仅仿真，不能直接连接SDK执行。旧v1/v2运行与成绩保留原行为，新`phase_version=insertion_guard_v3`运行才使用此退出流程。
